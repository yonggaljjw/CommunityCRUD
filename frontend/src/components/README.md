# components

특정 기능에 속하지 않고 여러 화면에서 재사용하는 UI를 둡니다.

- `Modal.vue`: 게시판과 채팅에서 함께 쓰는 공통 모달
- `layout/`: 헤더·사이드바·푸터처럼 화면 전체 골격을 만드는 컴포넌트

현재 공통 컴포넌트 수가 적으므로 `common/` 같은 중간 폴더를 추가하지 않았습니다.

## 기본 개념

### Vue Component

컴포넌트는 화면의 한 부분을 독립적으로 관리하는 단위입니다. 같은 UI/동작을 여러 곳에서 쓸 수 있고 부모 컴포넌트가 너무 커지는 것을 막아 줍니다.

### Props

부모가 자식에게 데이터를 전달할 때 사용합니다.

```text
부모 → props → 자식
```

`Modal.vue`는 `title`을 props로 받아 화면에 표시합니다.

### Emit

자식 컴포넌트가 부모에게 "어떤 일이 발생했다"고 알릴 때 사용합니다.

```text
자식 → emit("close") → 부모
```

모달 자체가 부모 상태를 직접 수정하지 않고 `close` 이벤트만 전달하는 식으로 결합도를 낮춥니다.

### Slot

컴포넌트의 일정 부분을 부모가 원하는 내용으로 채울 수 있게 하는 자리입니다. `Modal.vue`의 `<slot />` 덕분에 모달 외형은 재사용하면서 안쪽 내용은 화면마다 다르게 넣을 수 있습니다.

### Teleport

Vue의 `<Teleport to="body">`는 컴포넌트가 논리적으로는 현재 위치에 있어도 실제 DOM은 `body` 아래에 렌더링하게 합니다. 모달처럼 다른 레이아웃의 `overflow`나 z-index 영향을 피해야 하는 UI에 유용합니다.

## 언제 components로 옮길까?

특정 기능에서만 쓰는 컴포넌트라면 해당 `features` 폴더에 두고, 둘 이상의 기능에서 재사용되거나 앱 전체 UI 골격이면 `components`에 두는 것을 기본 기준으로 합니다.
