# utils

서버나 Vue 상태에 의존하지 않는 순수 도우미 함수를 둡니다. 현재는 한국어 날짜 표시 함수가 있습니다.

## 기본 개념

### Utility Function

여러 곳에서 반복해서 쓰는 작고 일반적인 계산/변환 기능을 별도 함수로 빼 놓은 것입니다.

예:

```text
서버 시간 문자열
  ↓ date utility
화면용 "09.23" 형식
```

### 순수 함수(Pure Function)

가능하면 utils의 함수는 같은 입력에 항상 같은 결과를 반환하고 외부 상태를 직접 수정하지 않는 형태가 좋습니다.

```js
result = format(input)
```

이런 함수는 Vue 컴포넌트나 서버 연결 없이도 독립적으로 이해하고 테스트하기 쉽습니다.

### 무엇을 utils에 넣지 말아야 하나?

- API 호출 → `services`
- 전역 상태 변경 → `stores`
- 특정 게시판 화면에만 필요한 로직 → `features/board`
- UI 자체 → `components`

단순히 "함수니까 utils"에 넣기보다 특정 기능과 결합되지 않은 재사용 가능한 계산인지 확인하는 것이 중요합니다.
